WebPrice

Built for DE.MI Europe

WebPrice is the web application that DE.MI Europe clients use to keep competitor prices under control. It lets you view surveys collected at rival supermarkets, track how prices change over time and keep an eye on ongoing promotions.

The Challenge

The previous system was built on a server-side rendering architecture with a fragmented UX that made quick data analysis cumbersome. The request was to start from scratch with a modern, reactive application designed for intensive daily use.

Goals

  • Replace the legacy system with a modern, fully responsive SPA
  • Deliver real-time dashboards and analytics across hundreds of survey campaigns
  • Handle data grids with 700+ rows and 80+ columns with filtering, sorting and optimised Excel export
  • Integrate promotional flyer viewing directly within the application
  • Implement secure authentication with JWT and rate limiting

Key Challenges

The most demanding technical points were: high-performance data grids (AG Grid with virtual scrolling), building a configurable index system supporting multiple formulas (Standard, Inverse, Coupled), and the real-time price delta calculation engine across multi-dimensional datasets (product × store × time period).

The Solution

I designed and developed the entire application: an Angular architecture with hierarchical routing, PrimeNG as the UI component library, AG Grid for data tables, Chart.js for charts and pdf.js for the flyer viewer. The backend is a minimal REST API in ASP.NET Core with JWT authentication.

Surveys — Prices

The core of the application. Each situation exposes three tabs:

  • Overview: store table with surveyed items, arithmetic and weighted indices, alongside a comparative bar chart
  • Detail: AG Grid with every product row and columns for each store — prices, promotions, original price and index per combination
  • Indices by category: index breakdown across 3-level ECR categories, comparing all surveyed stores

The Set filters panel lets users configure the index formula, the price used for calculation, promotional exceptions and the maximum accepted deviation.

A 3-month calendar showing scheduled survey campaigns via colour coding. Key KPIs are displayed: next survey date, total annual surveys, upcoming surveys in the next 30 days and completed ones.

Analysis Tools

Two supporting sections complete the system:

  • ECR Categories: a 5-level product category hierarchy (ECR standard) with search and the ability to enable/disable categories to refine analysis
  • Suppliers: product catalogue by supplier with full-text search, useful for quickly identifying all items from a brand across surveys

Technologies Used

Development

The project began with an in-depth analysis of end-user workflows, with the goal of reducing the number of clicks needed to reach critical information. The Angular architecture was structured with lazy-loaded feature modules to keep initial bundles small despite the application's size.

Methodology

  • Continuous iterations: frequent releases agreed with the client, with immediate feedback and rapid adjustments to emerging requirements
  • API-first: ASP.NET Core Minimal API backend developed in parallel with Scalar documentation, enabling independent frontend development with mocks
  • Performance focus: AG Grid with virtual scrolling for dense grids, server-side Gzip compression, route lazy loading and SQL query optimisation
  • Security: JWT authentication with refresh tokens, rate limiting on the login endpoint, CORS restricted to authorised domains
