GS Ballistics

GS Ballistics is an Android app for long-range shooting. Instead of relying on a guess in the field, it gives you a verified ballistic table: it numerically integrates air resistance and gravity along the whole trajectory, using the standard G1/G7 drag tables and a real atmosphere derived from temperature and pressure, not an approximate formula. It comes with a library of over 200 bullets, weapon and range profiles with field-verified elevations compared automatically against the calculated ones, a matching table and chart, and full data backup — no ads, no tracking, entirely offline. Built entirely with Claude Code ; I defined every design decision and validated every feature on real devices.

Setting up the data for a calculation

Before a reliable elevation can be read, four values must be set, in the following order: the reticle's angular unit, the ammo in use, the atmospheric conditions and the target distance.

Set the optic's reticle

The first value to define is the angular unit of the reticle mounted on the weapon: MOA or MRAD. It is set in the optics profile (Optics list → active profile), together with the click value (for example 0.25 MOA or 0.1 MRAD) and, if known, the turret's total travel. Every elevation the app calculates is expressed in this unit.

Select the ammo

The elevation calculation depends on the ballistic coefficient (BC) of the bullet in use: without an ammo selected, or with an incorrect BC, the calculated value can't be trusted. Ammo is chosen from the bullet library or entered manually in the weapon profile, specifying caliber, weight, muzzle velocity and both the G1 and G7 ballistic coefficients. Where both are available, GS Ballistics defaults to the G7 model: the G7 table represents a long-ogive boat-tail projectile and is more accurate for the modern match bullets typically used in long-range shooting. The G1 model (flat-base projectile) remains preferable for bullets shaped closer to that reference, or when the manufacturer only publishes a G1 BC — in that case the drag model should be set to G1 in the weapon profile.

Set air temperature and pressure

Air density and speed of sound, both used in the calculation, depend on temperature and atmospheric pressure: using values that don't match the real ones produces an elevation error that grows with distance. Temperature and pressure are set from the Settings screen and should be updated before every range session, based on the conditions measured in the field.

Set the target distance

With the reticle, ammo and atmospheric conditions defined, the target distance is set from the dial on the Home screen. The elevation calculated for that distance appears immediately, in the unit defined above. The distances offered on the dial are those of the active range: edit them from Range list → edit icon → "Distances" tab.

Set the shooting angle

Each target has its own uphill or downhill shooting angle, not the range as a whole: two targets on the same field can easily sit at different inclines, which is why the angle is set together with the distance, target by target, from the same "Distances" tab. An uphill or downhill shot needs less elevation than a level one at the same distance, and the difference grows with both the angle and the distance.

When the Home dial is set to a distance that doesn't exactly match a saved target, the angle used in the calculation is interpolated between the two nearest saved targets; past the farthest saved target, it stays fixed at that one's angle instead of being extrapolated further.

Scope and rifle configuration

One more set of values, entered once per weapon rather than per shot, also feeds the calculation: the zero range, the scope's height above the bore, the barrel's twist rate and any rail/ring offset. These live in their own "Scope and rifle configuration" screen, shared by every weapon profile — without them the elevation shown is still computed relative to the wrong zero geometry.

Home dashboard

The Home screen shows the elevation to dial for the selected distance, calculated from the currently active ammo and optic. To change the distance, use the dial: the elevation value updates automatically. On screen you'll find:

  • the currently active ammo and optic;
  • the distance dial, and the distance it's currently set to;
  • slope angle, temperature, pressure and muzzle velocity used in the calculation — each one opens its own quick-edit popup on tap;
  • the calculated elevation, shown in green if it has been verified on the range for that distance;
  • the horizontal windage.

Tapping "Slope angle" opens the same kind of popup as temperature and pressure. The "Use the phone's inclinometer" button reads the phone's own tilt sensor live — laid flat on top of the barrel or scope, with the phone's own top edge pointing toward the target — and keeps updating the value until stopped; from there it can also be corrected by hand before saving. Saving updates the active range only when the distance dialed on the gauge matches an already-saved target exactly — otherwise it only applies to this one reading, since the value shown in that case is already an interpolation between two targets, not data that belongs to that exact distance.

Verifying the number by hand

For anyone who wants to check the Home elevation against their own math, the "Elevation calculation" screen shows every intermediate step the engine used to get there — drop at the zero range and at the target, where the line of sight sits, the conversion to mrad or MOA — with the actual numbers behind that specific reading.

Bullet library and weapon profiles

The bullet library holds over 200 bullets with factory data from major manufacturers. Every weapon profile stores caliber, weight, muzzle velocity and the G1 and G7 ballistic coefficients. A profile can be created by selecting a bullet from the library — its data is pre-filled and can be edited — or by entering every value manually.

If a bullet is missing from the library, or the values shown look wrong, it can be reported directly from the Report tab of the ammo edit dialog: the report includes the data currently shown on that screen and an optional note field, and is sent as an email to the developer.

Verified shot correction

After a shot, the elevation actually verified can be logged for the distance and the weapon in use. The logged value is compared automatically against the calculated one and stays attached to that weapon/distance pair.

Chart

The same table, plotted as a curve, shows where along the trajectory the real value starts to depart from the calculated one. A second ammo, set as a comparison, can be overlaid on the same chart. There isn't just one chart: every table in the app (drop, retained velocity, retained energy, ranging error) has its own curve view, reachable with the same table/chart toggle icon.

The retained-velocity chart marks two transonic reference thresholds, Mach 1.2 and Mach 0.8, computed from the speed of sound at the set temperature. At the standard reference temperature and pressure (15°C, 1013 hPa) the speed of sound is about 340 m/s (Mach 1) — it shifts slightly at a different temperature, which is why the chart recomputes the two thresholds from the temperature set in Settings rather than from a fixed value. Based on that speed, every bullet's flight crosses three distinct bands:

  • Supersonic (above ~410 m/s, past Mach 1.2) — the regime the G1/G7 drag tables are calibrated best for and behave most predictably in; the condition most precision shots are planned to still be in when they reach the target.
  • Transonic (roughly 410 to 270 m/s, Mach 1.2–0.8) — drag coefficient shifts abruptly and less predictably, and gyroscopic stability can drop enough to produce noticeably wider dispersion: this is the band where group size tends to open up in a less controllable way.
  • Subsonic (below ~270 m/s, under Mach 0.8) — the bullet settles back into a relatively predictable regime again, with generally lower aerodynamic drag; the condition loads purpose-built to stay subsonic from the muzzle are designed around.

The zone to avoid, when possible, isn't subsonic itself — it's the transonic band. The goal is to pick a maximum working distance where the bullet still arrives comfortably inside the supersonic band, with margin above the threshold, or, for loads purpose-built for the subsonic band, to stay below its upper threshold the whole way. Crossing the transonic band in flight isn't a problem if it happens well before the target; it becomes one when it happens right around the distance actually being shot.

Exporting your data

The "Import & Export" entry in the main menu exports a single HTML file containing every weapon profile, range and rifle setting. The file opens right away, in whichever HTML viewer is set on the device: from there, like any other page, sharing it to Drive, email, WhatsApp or saving it among the files is still one tap away.

The exported file is both a readable report and a complete backup at once. Opened in any browser it shows the active weapon profile with its ballistic table, drop chart and retained-velocity chart, with the same dashed transonic thresholds shown above; every piece of data needed to restore the full configuration — including profiles not shown on screen — stays embedded in that same file, with no internet connection required. To restore it, on this device or another one, it's enough to import it from the same "Import & Export" menu entry.
